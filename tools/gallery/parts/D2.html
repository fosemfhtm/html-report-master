D2-01

데이터 모양이 바뀌는 3단계 파이프라인

언제 쓰나: 일렬로 이어지는 처리에서 각 단계의 입력과 출력을 구분한다.

예시 메일의 단어 횟수를 특징 벡터로 바꾸고 분류기가 스팸 점수 0.92를 계산한다. 가운데 단계는 텍스트를 수치 입력으로 바꾸는 역할을 맡는다.

D2-02

가설을 고치는 되돌림 과정

언제 쓰나: 분석 결과가 다음 실험 조건을 바꾸는 반복을 설명한다.

예시 밝은 곳에서 발아 길이가 길어졌어도 온도가 함께 달랐다면 광량의 효과를 분리하기 어렵다. 온도를 통제하는 조건을 새로 넣어 다음 측정을 설계한다.

D2-03

순환 단위의 내부와 시간 귀환

언제 쓰나: 한 번의 계산 내부와 다음 시점에 재사용하는 상태를 함께 설명한다.

예시 예측 위치 12 m와 관측 위치 14 m를 보정 이득 0.5로 섞으면 13 m가 된다. 위치 분산은 직전 3 m²에 과정 잡음 1 m²를 더해 4 m²가 되고, 관측 잡음 4 m²와 결합해 이득 4÷(4+4)=0.5, 보정 분산 2 m²를 얻는다.

D2-04

입력 묶음과 뉴런 열의 MLP 구조

언제 쓰나: 입력 변수의 의미와 층별 크기를 한 번에 연결한다.

예시 면적·층·역까지 거리를 학습 자료의 평균과 표준편차로 표준화해 3→4→3→1 구조에 넣는다. 각 선은 학습한 가중치이며, 마지막 선형층은 가격 한 개를 출력한다. 5.2억 원은 이 입력에 대한 예시 출력이다.

D2-05

한 관계식의 서로 다른 실물 적용

언제 쓰나: 같은 규칙이 대상의 크기와 배치가 달라도 적용되는 이유를 설명한다.

예시 각 평면의 점은 현재 위치, 벽 틈의 짙은 표식은 선택한 출구다. 가구·벽을 고려한 보행 경로 길이를 비교하면 세 건물 모두 서쪽 출구가 더 가깝다. 건물마다 다른 거리 값을 같은 최소 거리 규칙에 넣는다.

D2-06

타입 색 트리와 가지치기 피드백

언제 쓰나: 국소 가지 제거를 검증 성능으로 채택하거나 되돌리는 과정을 설명한다.

예시 분기 노드는 조건을 검사하고 잎 노드는 가격 구간을 반환한다. 층 조건을 제거하면 검증 정확도가 90%로 올라 채택한다. 다른 가지를 제거한 후보는 85%로 내려가므로 편집 전 트리로 되돌린다.

D2-07

반복 하위 구조의 공통 함수 추출

언제 쓰나: 여러 식에서 같은 계산을 찾아 하나의 재사용 함수로 묶는다.

예시 세 셀의 행 번호만 달라지고 세금 포함 금액을 반올림하는 구조는 같다. A2=10000, B2=0.1이면 원래 수식과 GROSS(A2,B2) 모두 11000을 반환한다. ROUND는 세 트리 바깥의 공통 마무리 연산이다.

Excel VBA의 공통 함수
Public Function GROSS(amount As Double, rate As Double) As Double
    GROSS = Application.WorksheetFunction.Round(amount * (1 + rate), 0)
End Function
D2-08

여러 사례의 매개변수 함수 일반화

언제 쓰나: 모양이 같은 계산의 서로 다른 상수를 함수 인자로 뽑아낸다.

예시 세 요금표는 기본요금 b와 km당 요금 r만 다르다. 짧은 거리에서는 기본요금이 낮은 B가 싸고, 5 km를 넘으면 km당 요금이 낮은 C가 싸다. 식 하나에 두 값을 넣으면 세 요금표를 모두 계산한다.

D2-09

공정 흐름과 국소 확장 지점

언제 쓰나: 기존 공정의 순서를 유지하며 새 기능이 들어갈 위치를 설명한다.

예시 주문 104의 무광 사진 6장은 보정·인화·포장을 차례로 거친다. 색상 프로필은 보정 단계에, 품질 검사는 인화 직후에 붙인다. 검사에서 색 편차가 큰 사진은 보정 단계로 돌려 다시 인화한다.

D2-10

편집 연산별 수식 트리 변화

언제 쓰나: 식의 값은 유지하며 트리 모양이 달라지는 연산을 비교한다.

예시 덧셈의 교환법칙으로 x를 왼쪽으로 옮기고, 결합법칙으로 상수 2와 3을 묶는다. 마지막에 상수 부분만 계산하면 x+5가 남는다. 이 예는 정수식이며 네 단계가 같은 값을 갖는다.

D2-11

모델 묶음 배포와 여러 환경 복제

언제 쓰나: 학습 산출물과 실행 환경을 분리하고 같은 모델의 재사용을 설명한다.

예시 면적·층·역까지 거리로 가격을 추정하는 FP32 ONNX 모델을 세 환경의 실행기에 복제한다. 가중치와 정규화 설정을 함께 고정한다. 서버는 여러 요청을 묶어 처리하고 모바일과 엣지는 각 기기에서 계산한다.

D2-12

작은 수를 대입한 계산량 비교

언제 쓰나: 복잡도 일반식의 차이를 실제 개수와 비교 연결로 해석한다.

전부 짝지어 비교
n(n − 1) / 2
8 → 28번

n = 1,000이면 499,500번

정렬한 뒤 이웃 비교
n log₂ n + (n − 1)
8 → 24 + 7 = 31번

n = 1,000이면 약 10,000 + 999 = 10,999번

예시 값 8개에서는 두 방법의 비교 횟수가 28번과 31번으로 비슷하다. 차이는 n이 커질 때 드러난다. 전수 비교는 n²에 비례해 늘고 정렬 방식은 n log n에 비례해 늘어서, 값 1,000개에서는 약 45배 차이가 난다.
