S1-01

문제에서 관측 근거로 내려가는 설명 흐름

언제 쓰나: 현상의 원인과 관측 결과를 차례로 연결해 연구 질문을 세울 때 쓴다.

문제 · 버스 몰림(bus bunching) 예시

같은 6분 배차도 정류장에서는 10분·2분 간격으로 벌어진다

앞 버스가 2분 늦으면 승객이 더 쌓인다. 승차 시간이 늘어 앞 버스는 더 늦어지고, 뒤 버스는 적은 승객을 태워 간격을 좁힌다.

쟁점 1 · 승차 수요

긴 간격에 승객이 모인다

분당 1명이 도착하면 10분 간격의 앞 버스에는 10명, 2분 간격의 뒤 버스에는 2명이 기다린다.

쟁점 2 · 정차 시간

승객 차이가 다음 지연을 만든다

1명당 승차 3초이면 정차 시간 차이는 24초다. 이 차이가 다음 정류장까지 이어진다.

관측 근거 · 연속 도착 시각

정류장직전 버스앞 버스뒤 버스앞 / 뒤 간격
A08:0008:0808:128분 / 4분
B08:1008:2008:2210분 / 2분

두 간격의 합은 12분으로 같고, 차이는 4분에서 8분으로 커진다. 평균 배차와 함께 간격의 불균형을 추적한다.

S1-02

전체 구조도와 세 단계 번호 요약

언제 쓰나: 복잡한 모델의 전체 위치를 먼저 잡고 세 단계의 역할을 기억하게 할 때 쓴다.

CNN · RGB 이미지에서 세 종류를 분류하는 구조 예시

  1. 합성곱 · 특징 추출3 × 3 필터 8개가 이미지 전체를 훑어 모서리와 질감에 반응하는 특징 맵을 만든다.
  2. 풀링 · 공간 압축2 × 2 영역의 최댓값을 남겨 32 × 32를 16 × 16으로 줄인다. 채널 8개는 유지한다.
  3. 분류 · 확률 산출2,048개 값을 세 점수로 바꾸고 Softmax로 정규화한다. 세 확률의 합은 100%다.
S1-03

전체 원자료와 탭별 부분 확대

언제 쓰나: 하나의 논문 그림을 전체 지도와 부분별 해설로 나누어 읽을 때 쓴다.

추천 시스템 · 후보 추출과 순위 결정의 두 단계 예시

후보 추출 · 10,000개 → 100개

사용자의 최근 클릭을 하나의 벡터로 묶고, 상품 벡터와 가까운 100개를 찾는다. 전체 상품 중 1%가 다음 단계로 넘어간다.

순위 결정 · 100개 → 10개

후보마다 사용자 선호, 상품 속성, 현재 맥락을 함께 점수화한다. 100개 중 상위 10개가 추천 목록을 이룬다.

S1-04

선택 가능한 실물 배치도와 고정 해설

언제 쓰나: 설비의 위치 관계를 유지한 채 각 공정의 기능을 자세히 읽을 때 쓴다.

정수장 · 세 공정 설비의 위치와 역할 예시

① 침전 · 중력 분리

천천히 흘려 입자를 모은다

탁도 20 → 2 NTU

응집된 입자가 바닥에 가라앉고 회전식 수집기가 슬러지를 모은다. 상부의 맑은 물은 가장자리 수로를 따라 여과지로 이동한다.

탁도는 물이 흐린 정도다. 이 공정의 예시 제거율은 90%다.

S1-05

방식 비교 카드와 용어 표의 연속 배치

언제 쓰나: 두 조사 방식의 직관적 차이를 설명한 뒤 표본수와 오차의 뜻을 정리할 때 쓴다.

예시 주민 10,000명의 자전거도로 찬성 비율을 조사한다.

전원 응답 시 표본추출 오차는 0이다. 응답 누락과 문항 해석 차이는 별도로 관리한다.

S1-07

공통 차트와 세 갈래 해석 카드

언제 쓰나: 하나의 결과를 규모·구성·운영 시사점으로 나누어 설명할 때 쓴다.

공유 자전거 · 한 달 이용 10,000건, 연령 확인 완료 건 기준 예시

규모

20대 이용 집중

20대의 3,600건은 40대 1,800건의 2배다. 연령대별 이용 건수를 기준으로 공급 규모를 검토한다.

구성

20·30대 합계 64%

두 연령대가 6,400건을 차지한다. 대학가와 업무지구의 대여·반납 시각을 이어 분석한다.

운영

연령과 시간대의 결합

50대 이상도 월 1,000건을 이용한다. 연령별 인구와 등록자 수를 결합해 1인당 이용 빈도를 산출한다.

S1-08

확인 결과와 후속 연구의 대응 배치

언제 쓰나: 현재 확인한 결과와 다음 실험을 구분하고 제약마다 실행 계획을 연결할 때 쓴다.

Wi-Fi 지문 기반 실내 측위 · 사무동 한 층, 60개 기준점 예시

확인한 것

고정 배치에서 위치 오차 감소

같은 스마트폰으로 수집한 독립 테스트 120회에서 중앙값 오차가 최근접 기준점 방식의 4.0m에서 가중 이웃 방식의 2.8m로 줄었다. 감소율은 30%다.

기준점 수집과 테스트는 서로 다른 날에 진행하고, AP와 가구 배치는 유지한다.
