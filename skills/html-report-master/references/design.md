# 디자인

빈 틀은 `assets/report_template.html`, 골라 쓰는 구조·도식·모형·차트는 `assets/gallery.html`(목록 `references/gallery.md`). 값은 틀의 `:root`가 기준이다.

## 1. 색

| 이름 | 값 | 쓰임 |
|---|---|---|
| `--bg` | `#f5f5f7` | 페이지 배경 |
| `--card` | `#fff` | 카드·표 |
| `--ink` / `--ink-2` / `--ink-3` | `#1d1d1f` / `#48484a` / `#6e6e73` | 제목 / 본문 / 보조 글씨 |
| `--line` | `#e5e5ea` | 장 구분선, 표 줄 |
| `--accent` / `--accent-soft` | 기본 `#004191` / `#e8eef5` | 장 번호, 버튼, 질문 번호, 공통 행, 차트의 주인공 계열 |
| `--ok` / `--warn` / `--bad` | `#248a3d` / `#b25000` / `#d70015` | 좋음 / 주의 / 나쁨 |

- 강조색은 보고서마다 하나. 시선이 한 색으로 모여야 장 번호와 버튼이 바로 눈에 띈다. 자료(코드 색 설정 → 그림 → 로고)에서 후보를 찾아 고르면 자료와 잘 어울린다. 기본값은 KAIST Dark Blue `#004191`.
- 두 개념 비교표의 열 제목에만 `--cmp-a`(주황)와 `--cmp-b`(강조색)를 쓴다.
- 그림자 `0 1px 2px rgb(0 0 0/.05), 0 8px 24px rgb(0 0 0/.06)`, 모서리 14px.

## 2. 글자

- Pretendard(가변, 100–900), 대체 글꼴은 Apple SD Gothic Neo, 맑은 고딕.
- 본문 20px / 1.65, 자간 -0.01em, `word-break: keep-all`. 한국어를 단어 단위로 줄바꿈해 단어가 두 줄로 갈라지는 일을 막는다.
- h1 52px, h2 38px, h3 22px, lead 22px, 주석 16px, 상단 바 15px.
- 900px 이하: 본문 17px, h1 36px, h2 28px, 모든 격자 1열.

## 3. 배치

- 읽기 폭 1120px, 데모처럼 넓은 칸만 1480px.
- 상단 고정 바: 로고 + 장 바로가기, 반투명 배경과 흐림.
- 표지: 날짜(eyebrow) → 제목 → 한 줄 요약 → 장 번호 칩.
- 장: 위쪽 구분선, 위 여백 64px. `번호 · 이름`(강조색, 작게) → h2 → lead → 내용.

| 부품 | 클래스 | 쓰임 |

| 이름표 카드 | `.card` + `.k` | 관점별 요점 3개 |
| 스크린샷 | `.shots`, `.shots--3`, `.shot` | 실제 화면. 누르면 라이트박스로 확대 |
| 핵심 문장 상자 | `.big` | 제품이나 주장의 정의. 보고서당 하나 |
| 비교표 | `.cmp` | 혼동하기 쉬운 두 개념의 구분. 마지막 행은 공통점 |
| 데모 칸 | `.demo`, `.demo-bar`, `.demo-frame` | 클릭 가능한 데모 iframe, 전체 화면 버튼 |

| 다음 단계 | `.next` | 질문 뒤 3단계 |
| 태그 | `.tag--real`, `.tag--mock` | 실제/예시 데이터 구분 |
| 링크 버튼 | `.linkbtn`, `.linkbtn--ghost` | 원본 서비스 열기, 새 탭·전체 화면 |
| 표 | `.tbl`, `tr.hl`, `.n` | 일반 표. 주인공 행 강조, 숫자 열 오른쪽 정렬 |

| 식 블록 | `.eq`, `.f`, `.sym` | 본문의 핵심 식과 기호 설명 한 줄. 식에만 `--math` 세리프 |
| 계산 보기 | `details.calc` | 유도, 세부 수치, 설정값 |
| 장 안 소목차 | `.subnav` | 하위 절이 많은 긴 장 |

## 5. 레이아웃 수정 사례

| 문제 | 수정 |
|---|---|
| 단계 카드의 번호와 글이 한 줄에 엉킴 | 번호를 위 줄에 두고, 아래에 제목과 설명 배치 |
| 목록 안 작은 설명이 본문에 붙음 | `small { display:block }`으로 줄 분리 |
| 데모 상단 바가 1240px 근처에서 넘침 | 미디어 쿼리로 버튼과 글자 축소 |

수정 뒤에는 1440px, 1240px, 900px 이하에서 스크린샷으로 배치를 다시 확인한다.

## 6. 파일 형태

- **단일 파일.** 글꼴(woff2), 이미지, 데이터를 base64로 넣는다. 그래야 드라이브에서 내려받은 파일 하나가 인터넷 연결 없이 크롬·엣지에서 열린다.
- **데모 삽입.** 데모 HTML은 base64로 넣고 Blob URL로 iframe에 띄운다. 데모 안의 `</script>`가 보고서의 스크립트를 끊지 않게 하기 위해서다. 전체 화면(`requestFullscreen`)과 새 탭 버튼을 둔다.
- **외부 주소.** 원본 서비스로 가는 링크만 둔다. 접속 정보가 필요한 서비스는 버튼 옆에 아이디와 비밀번호를 함께 적는다.
