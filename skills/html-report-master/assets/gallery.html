S1-01

문제에서 관측 근거로 내려가는 설명 흐름

언제 쓰나: 현상의 원인과 관측 결과를 차례로 연결해 연구 질문을 세울 때 쓴다.

문제 · 버스 몰림(bus bunching) 예시

같은 6분 배차도 정류장에서는 10분·2분 간격으로 벌어진다

앞 버스가 2분 늦으면 승객이 더 쌓인다. 승차 시간이 늘어 앞 버스는 더 늦어지고, 뒤 버스는 적은 승객을 태워 간격을 좁힌다.

쟁점 1 · 승차 수요

긴 간격에 승객이 모인다

분당 1명이 도착하면 10분 간격의 앞 버스에는 10명, 2분 간격의 뒤 버스에는 2명이 기다린다.

쟁점 2 · 정차 시간

승객 차이가 다음 지연을 만든다

1명당 승차 3초이면 정차 시간 차이는 24초다. 이 차이가 다음 정류장까지 이어진다.

관측 근거 · 연속 도착 시각

정류장직전 버스앞 버스뒤 버스앞 / 뒤 간격
A08:0008:0808:128분 / 4분
B08:1008:2008:2210분 / 2분

두 간격의 합은 12분으로 같고, 차이는 4분에서 8분으로 커진다. 평균 배차와 함께 간격의 불균형을 추적한다.

창고 현장과 네 가지 피킹 방식

언제 쓰나: 같은 현장에 적용하는 여러 방식을 실물 위치에 번호로 붙인 뒤 강점과 운영 과제를 비교할 때 쓴다.

예시 피킹은 선반에서 주문 상품을 꺼내 포장대로 모으는 작업이다. 네 방식은 같은 창고의 서로 다른 구간을 맡는다.

1

수작업

작업자가 선반 사이를 걸어 상품을 모은다.

강점 품목과 동선이 바뀌어도 바로 대응한다.

운영 과제 주문이 늘면 보행 거리가 처리량을 묶는다.

2

컨베이어

고정 경로로 상자를 포장대까지 연속 운반한다.

강점 고정 구간에서 끊김 없이 운반한다.

운영 과제 선반 배치를 바꾸면 설비도 옮긴다.

3

AGV

무인 운반차가 선반이나 상자를 작업자에게 가져온다.

강점 보행을 운반으로 바꿔 작업자는 집기만 한다.

운영 과제 교차 통로의 대기와 충전 순서를 관리한다.

4

로봇팔

포장대에서 같은 집기 동작을 반복한다.

강점 같은 동작을 일정한 속도로 반복한다.

운영 과제 새 포장재마다 그리퍼와 경로를 다시 맞춘다.

D2-12

작은 수를 대입한 계산량 비교

언제 쓰나: 복잡도 일반식의 차이를 실제 개수와 비교 연결로 해석한다.

전부 짝지어 비교
n(n − 1) / 2
8 → 28번

n = 1,000이면 499,500번

정렬한 뒤 이웃 비교
n log₂ n + (n − 1)
8 → 24 + 7 = 31번

n = 1,000이면 약 10,000 + 999 = 10,999번

예시 값 8개에서는 두 방법의 비교 횟수가 28번과 31번으로 비슷하다. 차이는 n이 커질 때 드러난다. 전수 비교는 n²에 비례해 늘고 정렬 방식은 n log n에 비례해 늘어서, 값 1,000개에서는 약 45배 차이가 난다.

언제 쓰나: 기호로 쓴 확률을 실제 인원과 연결하고 검사 결과의 두 목표를 구분할 때 쓴다.

01 · 양성 결과의 해석

양성 판정 뒤의 감염 확률

예시 유병률 1%, 민감도 90%, 특이도 95%인 검사를 10,000명에게 실시한다. 감염자 100명 중 90명, 비감염자 9,900명 중 495명이 양성 판정을 받는다.

P(D | +) = P(+ | D) P(D) / P(+)
D: 감염 · +: 양성 · P(D): 검사 전 감염 확률
P(+ | D): 감염자의 양성 확률 · P(D | +): 양성자의 감염 확률
0.90 × 0.01 / (0.90 × 0.01 + 0.05 × 0.99) ≈ 15.4%
양성 585명 = 감염 양성 90명 + 비감염 양성 495명 · 90 / 585 ≈ 15.4%

검사 전 감염자가 드문 집단에서는 비감염자에게서 나온 양성이 크게 쌓인다. 양성 판정 뒤 감염 확률은 유병률과 두 집단의 검사 반응을 함께 반영해 계산한다.

목표 A · 감염자 발견

감염자의 양성 비율 확대

민감도는 감염자 중 양성으로 찾아낸 비율이다. 예시에서는 감염자 100명 중 90명을 찾아내고 10명을 놓친다.

민감도 = 90 / 100 = 90%

목표 B · 비감염자 구분

비감염자의 음성 비율 확대

특이도는 비감염자 중 음성으로 구분한 비율이다. 예시에서는 9,900명 중 9,405명이 음성 판정을 받는다.

특이도 = 9,405 / 9,900 = 95%
